## 使用说明

下面的正则可直接复制,建议粘到 [正则表达式测试器](/regex) 里用你的真实数据验证一遍再用。示例默认不含首尾锚点,做整串校验时在两端加 `^` 和 `$`。

## 邮箱

```
[\w.+-]+@[\w-]+\.[\w.-]+
```
宽松够用版。整串校验加锚点:`^[\w.+-]+@[\w-]+\.[\w.-]+$`。

## 手机号(中国大陆)

```
1[3-9]\d{9}
```
以 1 开头、第二位 3-9、共 11 位。整串校验:`^1[3-9]\d{9}$`。

## URL

```
https?://[^\s]+
```
匹配 http/https 链接。更严格可限制域名与路径字符。

## IPv4 地址

```
\b(?:\d{1,3}\.){3}\d{1,3}\b
```
注意:这只校验"四段数字"格式,不保证每段 ≤ 255。

## 身份证号(中国大陆 18 位)

```
\d{17}[\dXx]
```
前 17 位数字 + 末位数字或 X。整串:`^\d{17}[\dXx]$`。

## 日期(YYYY-MM-DD)

```
\d{4}-\d{2}-\d{2}
```
如 2026-07-02。

## 中文字符

```
[一-龥]+
```
匹配一段连续中文。

## 数字(含负数与小数)

```
-?\d+(?:\.\d+)?
```
匹配 42、-3.14 等。

## 密码强度(至少 8 位,含大小写字母和数字)

```
(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}
```
用了三个前瞻分别要求包含小写、大写、数字。整串校验加 `^...$`。

## HTML 标签

```
<([a-zA-Z][\w-]*)[^>]*>
```
匹配开始标签并捕获标签名。复杂 HTML 解析仍建议用专门解析器,而非正则。
